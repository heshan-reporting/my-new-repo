Build it once. Ship it everywhere.

my-new-repo is a small, dependency-free starting point served straight from GitHub Pages. Clone it, edit one HTML file, push, and your site is live in about a minute.

View on GitHub Get in touch

What you get

No build step, no dependencies

Everything here is one HTML file and a deploy workflow. Nothing to install, nothing to keep up to date, nothing to break at 2am.

Instant deploys

Push to main and GitHub Actions publishes the site. Typical round trip is under a minute.

Plain HTML and CSS

No framework, no bundler, no lockfile. Open the file, change the text, and you are done.

Light and dark

Follows the visitor's system theme automatically, with contrast checked against WCAG AA in both.

Responsive by default

Fluid type and auto-fitting grids hold up from a 375px phone to a wide desktop with no media-query sprawl.
